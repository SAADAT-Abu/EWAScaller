## Update

This is an update of EWAScaller from 0.1.0 (on CRAN) to 0.2.0. Main
changes (see NEWS.md for the full list):

* New `ewas_eqtm()` and `eqtm_samples()` to retrieve expression
  quantitative trait methylation (eQTM) data from the EWAS Atlas web
  service, with new heatmap, volcano, tissue, and scatter plots.
* All plotting functions gain customisation arguments (colours, titles,
  theme, font size, label wrapping).
* Support for Illumina EPIC v2 probe identifiers and an `"EPICv2"`
  background option.
* Bug fixes: the default `background` of `ewas_enrichment()` no longer
  errors, `plot_wordcloud()` no longer changes the global random seed, and
  non-CpG `ch.*` probe identifiers are no longer rejected.

## Notes for reviewers

* Functions that contact the EWAS Atlas web service
  (<https://ngdc.cncb.ac.cn/ewas/>) are wrapped in `\donttest{}` in
  examples and skipped via `testthat::skip_on_cran()` /
  `skip_if_not(reachable)` in tests, so the check suite does not depend on
  network access or CRAN's test machines being able to reach the service.
* The vignette's live-API code chunks are set to `eval = FALSE` for the
  same reason; the vignette documents usage without requiring network
  access to build.
* `R/sysdata.rda` (0.84 MB, xz-compressed) holds an internal character
  vector of the Illumina probe identifiers present on both the EPIC v1 and
  EPIC v2 arrays, used to drop EPIC v2-only probes that the web service
  would reject. It is generated by `data-raw/epic_v1v2_probes.R` from
  Bioconductor annotation packages, which are only needed to regenerate
  the data and are not package dependencies.
